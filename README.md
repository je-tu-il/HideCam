# HideCam — Enregistreur local pour iPhone

Choisissez le microphone seul, la caméra avant, la caméra arrière ou le mode à deux caméras. Appuyez sur **Démarrer l’enregistrement**. Un compteur et un voyant signalent la capture. L’app arrête et finalise l’enregistrement lorsqu’elle passe en arrière-plan.

- Dans **Réglages**, choisissez la qualité vidéo et la destination.
- La localisation reste facultative, via le réglage de l’écran d’enregistrement.
- La galerie locale permet de retrouver les fichiers. Les modes à deux caméras dépendent du matériel.

Ouvrez `ios/StealthRecorder.xcodeproj` dans Xcode et exécutez le schéma **StealthRecorder**. Vérifiez les parcours caméra, microphone et Photos sur un iPhone physique avant d’archiver une version signée.
